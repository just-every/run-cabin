# Cabin contract

Native sessions guard each human API and document. Only owners grant access; managers approve exact immutable calendar, turnover and statement drafts. Cleaners read only assigned approved jobs and complete them with the approved checklist and a private photo. Bearer agents only prepare drafts.

Calendar imports are snapshots with explicit freshness; Cabin does not prevent double bookings. Calendar UID/channel reconciliation never adopts external edits silently. Statements freeze integer AUD cents and owner details at approval and never move money. Move-in uses Base import-kit custody, exact plan approval, durable journals and guarded undo. Local portability retains product data and excludes transient credentials, with erasure fencing for later-journal restore.

See ACCEPTANCE.md for the first release's jobs and docs/commands.md for command inputs.
